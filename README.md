# Sales and Revenue Analysis with SQL Server
# SQL Server ile Satış ve Gelir Analizi

---

## 🇬🇧 English

### Project Overview
This project analyzes sample sales data using Microsoft SQL Server (T-SQL). The goal is to identify revenue trends, compare product performance, and evaluate sales across cities and categories.

### Dataset
The sample dataset contains 10 sales records with the following fields:
- Sales ID
- Sales Date
- Product Name
- Category
- Quantity
- Unit Price
- City

### Analysis Questions
- What is the total revenue?
- Which products generate the most revenue?
- How does revenue change by month?
- Which cities generate the highest revenue?
- Which product categories perform best?
- What percentage of total revenue comes from each product?

### SQL Skills Demonstrated
- SELECT and calculated columns
- Aggregate functions: `SUM()`
- `GROUP BY` and `ORDER BY`
- Date functions: `YEAR()` and `MONTH()`
- Window functions: `OVER()`
- Revenue and percentage calculations

### Key Findings
- Total revenue: 241,150
- Highest-revenue product: Laptop
- Highest-revenue city: Istanbul
- Highest-revenue month: February 2026
- Highest-revenue category: Electronics

### Tools
- Microsoft SQL Server
- T-SQL
- GitHub

## 🇹🇷 Türkçe

### Proje Hakkında
Bu projede Microsoft SQL Server (T-SQL) kullanılarak örnek satış verileri analiz edilmiştir. Amaç, gelir eğilimlerini belirlemek, ürün performanslarını karşılaştırmak ve şehirler ile kategorilere göre satışları değerlendirmektir.

### Veri Seti
Örnek veri seti 10 satış kaydı içermektedir. Kullanılan alanlar:
- Satış ID
- Satış Tarihi
- Ürün Adı
- Kategori
- Adet
- Birim Fiyat
- Şehir

### Analiz Soruları
- Toplam ciro ne kadar?
- En fazla gelir getiren ürünler hangileri?
- Aylık ciro nasıl değişiyor?
- En yüksek ciro hangi şehirde elde ediliyor?
- En çok gelir getiren ürün kategorisi hangisi?
- Her ürünün toplam gelir içindeki payı yüzde kaç?

### Gösterilen SQL Becerileri
- SELECT ve hesaplanan sütunlar
- Toplama fonksiyonları: `SUM()`
- `GROUP BY` ve `ORDER BY`
- Tarih fonksiyonları: `YEAR()` ve `MONTH()`
- Pencere fonksiyonları: `OVER()`
- Ciro ve yüzde hesaplamaları

### Temel Bulgular
